# 健身房管理系统 · MVP 立项说明

> 日期：2026-10-28 ｜ 状态：**一期已交付（业务逻辑跑通，可离线运行）**

---

## 一、目标（这个 MVP 到底为了什么）

**一句话**：用最短时间做出一个「双击就能打开、点一遍就明白健身房怎么运转」的可点击雏形。

它同时服务两个目的：

1. **给大圣自己用** —— 把"会员从进店到续卡"的完整链路跑一遍，看清每个环节要记什么数据、谁操作、数据怎么流转。逻辑通顺了再谈正式版。
2. **给外人演示** —— 健身房老板 / 合伙人坐下来五分钟能看懂这套系统在管什么、能解决什么问题。

**它不追求**：真实营业数据、多设备同步、硬件对接、复杂权限配置。这些留给正式版。

## 二、内容（MVP 具体包含哪些页面）

### 后台（PC）

| # | 页面 | 这一页解决什么 |
|---|---|---|
| 0 | **导览首页** | 一屏总览：业务流程图 + 五个角色分工 + 数据流向，先建立全局认知 |
| 1 | **经营看板** | 今天店里什么情况：到店人次、新增会员、今日实收、待办提醒 |
| 2 | **会员管理** | 会员档案列表 + 详情（持卡、消费、上课、入场、跟进记录一屏看完） |
| 3 | **卡项与办卡** | 卡模板长什么样 + 给会员开卡，开完卡自动算业绩提成 |
| 4 | **收银台** | 选会员 → 选卡 → 选支付方式 → 开单，右侧同步显示今日流水 |
| 5 | **入场签到** | 前台搜手机号 → 系统自动校验卡是否有效 → 一键确认入场 |
| 6 | **课程预约** | 周课表日历 + 点课程看报名名单 + 核销扣次数/课时 |
| 7 | **财务业绩** | 订单流水 + 员工业绩榜 + 教练课时结算表 |
| 8 | **员工管理** | 员工档案、角色、提成比例与课时费设置 |

### 会员端（手机视图）

| # | 页面 | 这一页解决什么 |
|---|---|---|
| 1 | **我的卡** | 剩余天数 / 剩余次数 / 剩余课时，到期日一眼看到 |
| 2 | **课表预约** | 本周排课，在线预约和取消 |
| 3 | **我的预约** | 即将上课 + 历史记录 |
| 4 | **个人中心** | 资料与消费记录 |

### 权限演示

顶部一个**角色切换下拉**：老板 / 店长 / 前台 / 教练 / 会员。切换后左侧菜单和可见数据立刻变化——这是理解权限差异最快的方式（正式版换成真实账号登录）。

## 三、明确不做（这就是"简单点"的边界）

这些东西**MVP 一律不做**，避免一开始就被细节拖死：

- ❌ 真实登录注册、手机验证码、密码找回 → 用角色下拉代替
- ❌ 云端数据库、多设备同步 → 数据存本地浏览器
- ❌ 退卡、转卡、停卡审批流 → 只做入口占位，标注"正式版"
- ❌ 候补队列、自动递补、到课提醒推送
- ❌ 员工排班日历、考勤
- ❌ 规则配置后台（预约截止时间、提醒天数）→ 写死默认值，页面上标注"正式版可调"
- ❌ 打印小票、导出 Excel、门禁/闸机对接
- ❌ 多店切换界面（数据结构预留字段，UI 不做）
- ❌ 图表只做柱状图和条形榜，不做复杂 BI

## 四、要求（验收标准，做完了拿这 6 条卡）

1. **一键开启**：双击 `一键启动.bat`（或直接双击 `index.html`）就能在浏览器打开。零安装、零命令行、断网可用。
2. **三击可达**：任何页面从主导航起 3 次点击内到达。
3. **每页一句人话**：每个页面顶部写清楚"这页管什么、点哪里"，不给说明书也能看懂。
4. **数据记得住**：任何改动实时存在本地，关掉再开还在；提供"一键恢复演示数据"。
5. **角色切换即时生效**：切角色后菜单和可见内容马上变，前台看不到财务报表。
6. **数字自洽**：在收银台开一张卡，看板营收、会员持卡、业绩榜三处同步变化——不允许出现各页面数字打架。

## 五、交付形态

```
gym-mvp/
  index.html          ← 双击这个就开
  一键启动.bat         ← 或者双击这个
  assets/
    styles.css
    mock-data.js      演示数据（会员/卡/课程/订单）
    app.js            页面与交互逻辑
```

技术：纯 HTML + CSS + 原生 JS，**不依赖任何外部库和网络 CDN**，所以断网也能跑。数据存浏览器 localStorage。

## 六、做完之后的下一步

MVP 确认没问题后，正式版要补的就是第三节被砍掉的部分，优先级建议：

1. 真实账号登录 + 云端数据（这样前台、教练、会员各用各的设备）
2. 完整的财务与提成计算
3. 会员微信小程序（约课体验最好）
4. 多店支持
